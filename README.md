# Employee Management System

Full-stack application with Spring Boot backend and React frontend.

## Features
- REST APIs with Spring Boot & JWT (authentication)
- React UI consuming backend
- MySQL database integration
- CRUD operations on employee data

## Tech Stack
- Java
- Spring Boot
- JWT Authentication
- React.js
- MySQL

## Run Instructions
1. Run backend: cd backend
                mvn spring-boot:run

3. Run frontend: cd frontend
                 npm install
                 npm start
